# 04 - 测试执行与报告

> **适用版本**: v0.1.3+ | **目标读者**: 有自动化测试经验的测试工程师

---

## 概述

「测试执行」Tab 是平台的中央调度界面，负责：

- 测试目录选择与文件管理
- 测试计划的创建、编辑、删除
- 测试类型筛选（基于 Pytest markers）
- 测试执行（实时日志输出 + 进度追踪）
- Allure 报告查看与历史记录
- 测试服务器管理

![测试执行主界面](../images/04-test-execution-main.png)

---

## 界面布局

| 区域 | 位置 | 内容 |
|------|------|------|
| **左侧面板** | 上半部分 | 测试目录 + 测试文件列表 |
| | 中部 | 测试计划管理（选择目录后显示） |
| | 下半部分 | 测试类型筛选 + 定时计划管理 |
| **右侧面板** | 上半部分 | 实时测试输出日志 |
| | 下半部分 | 进度条 + 控制按钮（运行/停止/查看报告/停止服务器） |

---

## 整体流程

```
选择测试目录 → 创建测试计划 → 选择测试类型 → 运行测试 → 查看报告
```

---

## 步骤 1：选择测试目录

点击「选择测试目录」按钮，选择包含 Python 测试脚本的文件夹。

目录选择后发生以下变化：
- 左侧「测试文件列表」显示目录内所有 `.py` 测试文件（带复选框）
- 「测试计划」卡片解锁
- 「测试类型」卡片加载 Pytest markers
- 「定时计划」卡片解锁

![选择测试目录](../images/04-select-directory.png)

---

## 步骤 2：创建测试计划

### 2.1 弹出新建计划弹窗

点击「新建计划」按钮（目录已选后解锁），弹出计划编辑弹窗。

![新建计划弹窗](../images/04-new-plan-modal.png)

### 2.2 配置计划参数

| 参数 | 说明 | 是否必填 |
|------|------|----------|
| **计划名称** | 计划的标识名称 | 是 |
| **计划描述** | 计划说明文字 | 否 |
| **测试文件** | 勾选要执行的 `.py` 测试文件（从目录中加载） | 至少选一个 |
| **测试类型** | 勾选要执行的 Pytest markers（如 smoke、regression） | 可选（不选则执行全部） |
| **循环次数** | 测试循环执行次数（默认 1，范围 1~999） | 是 |
| **失败后继续** | 勾选后，某次循环失败时继续执行后续循环 | 否 |

> [!WARNING]
> 如果没有勾选任何测试类型，系统将执行目录中所有测试，不计 marker 过滤。

![计划参数配置](../images/04-plan-config.png)

### 2.3 保存计划

点击「保存」，计划写入 `config/test_plans.json`，左侧计划列表刷新。

---

## 步骤 3：选择测试类型

在「测试类型」卡片中勾选要执行的 marker：

- 所有可选 markers 来源于 `config/pytest.ini` 中的定义
- 类型勾选状态将作为运行参数传递给 Pytest（`-m "marker1 or marker2"`）

![测试类型选择](../images/04-test-type-select.png)

---

## 步骤 4：运行测试

### 4.1 启动测试

点击「运行测试」按钮，系统将：

1. 调用 Python 子进程执行 `python -m main`
2. 实时将 stdout/stderr 输出到右侧日志面板
3. 进度条动态更新（基于测试文件数量推算）

### 4.2 运行中操作

| 操作 | 按钮 | 效果 |
|------|------|------|
| 停止测试 | **停止测试** | 终止子进程，停止当前执行 |
| 查看日志 | 滚动右侧面板 | 实时查看 `pytest` 输出和断言结果 |

![测试运行中](../images/04-test-running.png)

### 4.3 测试完成

测试执行完毕（正常结束或被终止）后：

- 进度条归零
- 「查看报告」按钮解锁
- 「停止服务器」按钮解锁

---

## 步骤 5：查看报告

### 5.1 打开报告选择器

点击「查看报告」按钮，弹出报告选择弹窗。

弹窗中列出当前选中测试计划的**所有历史运行记录**。

![报告选择弹窗](../images/04-report-modal.png)

### 5.2 选择运行记录

- 每条记录显示执行时间戳
- 选中一条记录后「打开报告」按钮解锁
- 点击「打开报告」在默认浏览器中启动 Allure 报告页面

Allure 报告包含：
- 测试概览（通过/失败/跳过数量）
- 按 Suite/Epic/Feature/Story 分类
- 每个用例的详细步骤与截图
- 失败用例的错误堆栈

![Allure报告](../images/04-allure-report.png)

### 5.3 停止 Allure 服务器

报告查看完毕后，点击「停止服务器」关闭 Allure 本地服务，释放端口。

---

## 管理测试计划

### 编辑计划

选中一个计划 → 点击「编辑计划」→ 在弹窗中修改 → 点击「更新计划」。

### 删除计划

选中一个计划 → 点击「删除计划」→ 确认删除。

> [!CAUTION]
> 删除计划**不会**删除对应的测试用例文件和测试脚本，仅移除计划元数据。

## 测试类型与 Pytest 集成

`config/pytest.ini` 中可自定义 markers：

```ini
[pytest]
markers =
    smoke: 冒烟测试
    regression: 回归测试
    login: 登录相关测试
    payment: 支付相关测试
```

平台上勾选的类型将映射为 `pytest -m "smoke or regression"` 参数。
