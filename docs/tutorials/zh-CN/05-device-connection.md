# 05 - 设备连接与投屏

> **适用版本**: v0.1.3+ | **目标读者**: 有自动化测试经验的测试工程师

---

## 概述

「安卓连接」Tab 提供 Android 设备的全生命周期管理：

- 设备发现与连接（USB / 无线 ADB）
- 设备信息查看（制造商、型号、Android 版本、WiFi、电量、存储、内存）
- Scrcpy 屏幕镜像与控制
- 文件管理器（浏览、上传、下载、删除、重命名）
- APK 一键安装到设备
- 蓝牙 Mock 设备串口端口管理

![安卓连接主界面](../images/05-device-main.png)

---

## 整体流程

```
连接设备 → 查看设备信息 → （可选）启动投屏 → （可选）文件管理/APK安装
```

---

## 步骤 1：连接设备

### 1.1 设备管理弹窗

点击「设备管理」按钮，弹出设备管理弹窗。

弹窗自动扫描已连接的设备（USB 连接 + ADB 无线连接）：

![设备管理弹窗](../images/05-device-management.png)

### 1.2 选择设备

- 左侧列表显示所有可用设备
- 点击设备条目查看右侧详细设备信息
- 点击「确认选择」确认当前设备

### 1.3 通过 IP 添加设备

如果设备不在列表中（如需要无线连接）：

1. 点击列表中的「按IP新增设备」
2. 输入 IP 地址或 `IP:端口`（默认端口 5555）
3. 点击 ✓ 确认连接

![添加IP设备](../images/05-add-device-ip.png)

### 1.4 开放 5555 端口

对于已通过 USB 连接的设备，选中后点击「开放5555端口」按钮，系统执行 `adb tcpip 5555`，使设备支持无线 ADB 连接。

> [!NOTE]
> 开放端口后需要将 USB 断开，通过 IP 方式无线连接。

---

## 步骤 2：查看设备信息

成功选择设备后，左侧「设备信息卡片」解锁，显示实时设备状态：

| 信息项 | 获取方式 |
|--------|----------|
| **制造商** | `adb shell getprop ro.product.manufacturer` |
| **型号** | `adb shell getprop ro.product.model` |
| **Android版本** | `adb shell getprop ro.build.version.release` |
| **连接WiFi** | `adb shell dumpsys netstats | grep ...` |
| **电池电量** | `adb shell dumpsys battery` |
| **存储使用** | `adb shell df` |
| **内存使用** | `adb shell dumpsys meminfo` |

![设备信息](../images/05-device-info.png)

---

## 步骤 3：屏幕控制（Scrcpy）

### 3.1 启动投屏

选择设备后点击「屏幕控制」按钮，启动 Scrcpy 投屏窗口：

- 实时镜像设备屏幕
- 鼠标可直接操作设备界面
- 支持剪贴板同步

### 3.2 配置控制参数

点击「控制参数」按钮，弹出参数配置弹窗：

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| **最大分辨率** | 视频输出最大宽度 | 1920 | 320~6000 |
| **视频比特率** | 视频质量 | 8 Mbps | 1~50 |
| **最大帧率** | 刷新率 | 60 FPS | 1~600 |
| **视频编解码器** | 编码格式 | h264 | h264 / h265 / av1 |
| **始终置顶** | 投屏窗口保持在最上层 | 开启 | 开/关 |

这些参数可从「设置 → 通知」页面的全局配置继承默认值。

![控制参数弹窗](../images/05-control-params.png)

> 控制参数中的默认值继承自 `config/config.json` 中的 `SCRCPY_PARAMS`。

---

## 步骤 4：文件管理

右侧面板提供 Android 设备的文件管理器，功能类似桌面资源管理器。

### 4.1 导航操作

| 操作 | 按钮/方式 |
|------|-----------|
| **进入目录** | 点击目录行 |
| **返回上级** | 「返回」按钮 |
| **刷新** | 「刷新」按钮 |
| **路径跳转** | 点击路径显示区的 `...` 按钮，弹出路径层级菜单 |
| **全选** | 点击表头复选框 |

![文件管理器](../images/05-file-manager.png)

### 4.2 文件操作

| 操作 | 按钮 | 说明 |
|------|------|------|
| **上传** | 「上传」 | 选择本地文件上传到设备当前目录 |
| **下载** | 「下载」 | 下载设备文件到本地（显示进度条） |
| **删除** | 「删除」 | 删除选中文件/目录 |
| **重命名** | 右键菜单 → 重命名 | 修改文件或目录名称 |
| **安装APK** | 「安装APK」 | 选择本地 APK 文件安装到设备 |

> [!TIP]
> 右键点击文件行可唤出上下文菜单（下载 / 重命名 / 删除）。

### 4.3 下载进度

下载操作显示实时进度条：

- 进度百分比 + 当前文件/总文件数
- 5 秒倒计时自动关闭进度面板
- 下载失败时显示错误详情

![下载进度](../images/05-download-progress.png)

---

## 步骤 5：APK 安装

在文件管理器中：

1. 点击 **「安装APK」** 按钮
2. 在文件选择对话框中选择 `.apk` 文件
3. 系统通过 `adb install` 将 APK 安装到当前选中设备

安装进度（包括成功/失败状态）通过 IPC 事件实时推送到界面。

---

## 蓝牙 Mock 设备端口管理

在设备管理弹窗中，可以管理蓝牙 Mock 设备所需的串口端口：

### 端口扫描

点击「端口管理」按钮自动扫描系统可用串口（COM 端口）。

### 选择端口

从扫描到的端口列表中选择蓝牙 Mock 设备占用的端口，确认后关联到当前测试配置。

![端口管理](../images/05-port-management.png)

蓝牙设备的完整配置（名称、波特率、数据格式等）见 `config/ble_device.json`。

---

## 命令参考

设备管理本质是将 ADB 命令封装为图形化操作，常用对应关系：

| GUI 操作 | 底层命令 |
|----------|----------|
| 扫描设备 | `adb devices` |
| 开放5555端口 | `adb tcpip 5555` |
| IP连接 | `adb connect <ip>:5555` |
| 文件列表 | `adb shell ls -al <path>` |
| 上传文件 | `adb push <local> <remote>` |
| 下载文件 | `adb pull <remote> <local>` |
| 安装APK | `adb install <apk>` |
| 启动投屏 | `scrcpy --max-size=1920 ...` |
