# 07 - 系统设置

> **适用版本**: v0.1.3+ | **目标读者**: 有自动化测试经验的测试工程师

---

## 概述

「设置」Tab 集中管理平台的所有可配置项，涵盖 6 大类别：

| 类别 | 覆盖内容 |
|------|----------|
| **目录** | 默认下载路径、配置数据存放位置 |
| **显示** | 暗色模式、主题色、界面语言 |
| **通知** | DingTalk 机器人推送配置 |
| **数据** | Allure 报告清理、日志清理 |
| **运行** | 防系统睡眠开关 |
| **更新** | 自动更新开关、手动检查更新 |

所有设置持久化存储在 `config/config.json`。

---

## 目录设置

### 默认下载路径

设置从设备下载文件时的默认保存目录：

1. 点击「浏览」按钮选择目录
2. 路径显示在输入框中
3. 点击「清除」恢复为空（下载时手动选择）

### 配置存放位置

自定义用户数据（测试用例、计划、页面封装、蓝牙设备等）的存储路径：

| 操作 | 按钮 | 说明 |
|------|------|------|
| **自定义路径** | 「浏览」 | 选择目标文件夹 |
| **恢复默认** | 「恢复」 | 重置为系统 AppData 目录 |

**首次设置时**，系统会将默认配置从安装目录复制到新路径，并完成数据迁移。

> 更改配置存放位置会触发应用重启，请确保当前没有正在执行的测试。

## 显示设置

### 暗色模式

| 状态 | 效果 |
|------|------|
| **开启** | 全局暗色主题，降低屏幕亮度，适合夜间使用 |
| **关闭** | Material Design 亮色主题 |

切换立即生效，无需重启。

### 主题色

系统预设 5 种主题色，也可手动输入 HEX 色值：

| 预设色 | HEX |
|--------|-----|
| 蓝 | `#2196F3` |
| 绿 | `#4CAF50` |
| 橙 | `#FF9800` |
| 紫 | `#9C27B0` |
| 红 | `#F44336` |
| 棕 | `#795548` |
| **自定义** | 在输入框中输入任意 HEX 值（如 `#00BCD4`） |

主题色应用于导航栏、按钮、进度条等 UI 元素。

### 语言

| 选项 | 值 |
|------|-----|
| 简体中文 | `zh-CN` |
| English | `en-US` |

切换后界面文本即时更新（通过 i18next 实现），无需刷新。

## 通知设置

XKAutoTester 支持测试完成后通过 DingTalk（钉钉）机器人推送报告摘要。

### 选择通知平台

| 选项 | 说明 |
|------|------|
| **无** | 不发送任何通知 |
| **钉钉** | 通过 DingTalk 机器人 Webhook 推送 |

选择「钉钉」后，下方将显示 Access Token 和 Secret 输入框。

### 配置 DingTalk 机器人

| 参数 | 说明 | 获取方式 |
|------|------|----------|
| **Access Token** | 机器人 Webhook 地址中的 `access_token` 参数 | 钉钉群 → 群设置 → 智能群助手 → 添加机器人 → Webhook 地址 |
| **Secret** | HMAC-SHA256 签名的密钥 | 机器人安全设置 → 加签 → 复制 Secret |

#### 配置步骤

1. 在钉钉群中创建自定义机器人，选择「加签」安全方式
2. 将 Webhook 地址中的 `access_token` 值填入 Token 输入框
3. 将加签的 Secret 填入 Secret 输入框
4. 保存配置

测试完成后，系统将通过 HMAC-SHA256 签名算法向 Webhook 地址 POST 测试摘要：

- 测试计划名称
- 通过/失败/跳过数量
- 执行耗时
- 报告链接（如有）

## 数据管理

### 清空 Allure 报告数据

点击「清空」按钮删除所有历史 Allure 报告结果文件，释放磁盘空间。

> [!CAUTION]
> 此操作不可恢复，历史报告数据将被永久删除。

### 清除所有日志

点击「清空」按钮删除应用程序运行日志文件。

---

## 运行设置

### 防系统睡眠

| 状态 | 效果 |
|------|------|
| **开启** | 测试执行期间，通过 `powerSaveBlocker` API 阻止 Windows 进入睡眠/休眠 |
| **关闭** | 系统睡眠策略不受影响 |

> 长时间执行的测试计划（特别是定时计划）建议开启此选项。

---

## 更新设置

### 自动检查更新

| 状态 | 效果 |
|------|------|
| **开启** | 应用启动时自动检查 GitHub Releases 是否有新版本 |
| **关闭** | 仅手动检查 |

### 手动检查更新

点击「立即检查」按钮：

1. 系统查询 GitHub Releases API
2. 如果有新版本，弹出「版本更新」弹窗，显示新版本号和 Changelog
3. 点击「下载更新」下载新版本安装包（带进度条）
4. 下载完成后点击安装，应用将自动重启完成更新

## 配置文件结构

所有设置存储在 `config/config.json`：

```json
{
  "LOG_CONFIG": {
    "level": "INFO",
    "format": "%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    "file_path": ".",
    "max_bytes": 10485760,
    "backup_count": 5
  },
  "SCRCPY_PARAMS": {
    "max_size": "1920",
    "video_bit_rate": "8",
    "max_fps": "60",
    "video_codec": "h264",
    "always_on_top": true
  },
  "APP_SETTINGS": {
    "default_download_directory": "",
    "dark_mode": false,
    "theme_color": "#4CAF50",
    "language": "zh-CN",
    "notification": {
      "platform": "none",
      "dingtalk": {
        "access_token": "",
        "secret": ""
      }
    },
    "autoCheckUpdate": true
  }
}
```

---

## 配置同步与迁移

- 应用升级时，`UserDataService` 自动将安装包新增的配置项合并到用户配置中
- 用户自定义配置（AppData 目录下）不受安装包升级影响
- 可通过「配置存放位置」将用户数据迁移到自定义路径
