# 03 - 页面元素封装

> **适用版本**: v0.1.3+ | **目标读者**: 有自动化测试经验的测试工程师

---

## 概述

「页面封装」模块实现 **应用 → 页面 → 元素** 三级管理，用于维护被测 App 的 UI 元素定位器。测试用例通过引用此处的元素定位器来实现与界面的交互，避免在每个用例中硬编码定位信息。

```
应用 (App)
  └── 页面 (Page)
       └── 元素 (Element)
            ├── 定位器类型: id / xpath / accessibility_id / css / class_name
            └── 定位器值: 实际的定位表达式
```

---

## 整体流程

```
添加应用（APK自动解析） → 添加页面 → 添加元素定位器 → 在测试用例中引用
```

---

## 步骤 1：添加应用

### 1.1 弹出应用弹窗

在应用选择下拉框中点击 **+** 按钮，弹出「新增应用」弹窗。

### 1.2 填写应用信息

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **应用名称** | 应用的友好名称（如"微信"） | 是 |
| **APK 识别区域** | 拖放 APK 文件自动解析 | 否 |
| **平台** | 固定为 Android | 是 |
| **包名** | 应用 Android 包名（如 `com.tencent.mm`） | 是 |
| **Activity名称** | 应用启动 Activity（如 `.ui.LauncherUI`） | 否 |

### 1.3 使用 APK 自动解析（推荐）

将 APK 文件拖放到「APK 识别区域」中，系统通过 aapt2 自动提取：

- **包名** (`package`)
- **启动 Activity** (`launchable-activity`)

解析成功后面板变为绿色 "解析成功"，表单字段自动填充。

> [!TIP]
> 使用 APK 解析可避免手动查询包名和 Activity，减少人为错误。

### 1.4 保存应用

点击「保存」按钮，应用信息写入 `config/page_package.json`。

---

## 步骤 2：添加页面

### 2.1 选择应用

在应用下拉框中选中刚创建的应用，页面选择区解锁。

### 2.2 弹出页面弹窗

在页面选择下拉框中点击 **+** 按钮，弹出「新增页面」弹窗。

### 2.3 填写页面信息

| 字段 | 说明 | 示例 |
|------|------|------|
| **页面名称** | 界面名称 | `登录页`、`首页`、`设置页` |

### 2.4 保存页面

点击「保存」，页面挂载到当前应用下。

---

## 步骤 3：添加元素定位器

### 3.1 选择页面

在页面下拉框中选中已创建的页面，元素选择区解锁。

### 3.2 弹出元素弹窗

在元素选择下拉框中点击 **+** 按钮，弹出「新增元素」弹窗。

### 3.3 配置定位器

| 字段 | 说明 | 示例 |
|------|------|------|
| **元素名称** | 元素的友好名称 | `用户名输入框`、`登录按钮`、`密码输入框` |
| **定位器** | 元素定位策略 | 下拉选择，支持 5 种类型 |
| **定位值** | 实际定位表达式 | 根据定位器类型填写 |

### 定位器类型说明

| 定位器 | 适用场景 | 示例值 |
|--------|----------|--------|
| **id** | 元素有 `resource-id` | `com.example:id/btn_login` |
| **xpath** | 复杂层级定位 | `//android.widget.Button[@text='登录']` |
| **accessibility_id** | 元素有 `content-desc` | `login_button` |
| **css** | WebView 内嵌页面 | `.login-form .submit-btn` |
| **class_name** | 按类名定位 | `android.widget.EditText` |

> 推荐优先级：`id` > `accessibility_id` > `xpath` > `class_name` > `css`

### 3.4 保存元素

点击「保存」，元素挂载到当前页面下。

---

## 步骤 4：管理封装数据

### 三级级联选择器操作

每个下拉框提供统一的操作按钮：

| 按钮 | 功能 |
|------|------|
| **+** | 新增（应用/页面/元素） |
| **✎（编辑）** | 编辑当前选中项 |
| **🗑（删除）** | 删除当前选中项 |

选中一个条目后，编辑/删除按钮解锁。

### 搜索过滤

每个下拉框顶部有搜索输入框，输入关键字实时过滤列表项。

### 数据统计

每个下拉框标题右侧显示当前选中层级下的条目数量：

- 应用数 → 显示在应用选择区
- 页面数 → 显示在页面选择区
- 元素数 → 显示在元素选择区

---

## 与测试用例的集成

在「测试用例」Tab 中创建用例时：

1. **选择应用** — 从页面封装的应用列表中选择
2. **配置步骤** — 每个步骤的「目标页面」从当前应用的页面列表中选择
3. **选择元素** —「目标元素」从目标页面的元素列表中选择

测试用例生成的 Python 代码将自动引用此处的定位器，无需在代码中硬编码。

## 数据结构示例

```json
{
  "apps": [
    {
      "id": "app_001",
      "name": "示例应用",
      "platform": "android",
      "packageName": "com.example.app",
      "activityName": "com.example.app.MainActivity",
      "pages": [
        {
          "id": "page_001",
          "name": "登录页",
          "elements": [
            {
              "id": "elem_001",
              "name": "用户名输入框",
              "locator": "id",
              "value": "com.example:id/et_username"
            },
            {
              "id": "elem_002",
              "name": "密码输入框",
              "locator": "id",
              "value": "com.example:id/et_password"
            },
            {
              "id": "elem_003",
              "name": "登录按钮",
              "locator": "xpath",
              "value": "//android.widget.Button[@text='登录']"
            }
          ]
        }
      ]
    }
  ]
}
```
